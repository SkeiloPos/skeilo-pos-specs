# Administración Global

Este módulo documenta las funciones exclusivas del equipo interno de SkeiloPOS (rol Super Admin)
para operar la plataforma como un todo: dar de alta negocios nuevos, asignarles un plan de
suscripción con sus límites y accesos, y administrar los catálogos y datos compartidos entre
todos los negocios, como el catálogo de métodos de pago y la lista de nombres reservados para la
propia plataforma. Le sirve a cualquier integrante de soporte que necesite explicar, con
precisión, cómo se da de alta un cliente nuevo o por qué una función determinada no está
disponible desde el panel de un negocio normal.

Orden de lectura recomendado:

1. [Gestión de tenants y planes de suscripción](gestion-de-tenants-y-planes.md): cómo se crea un
   negocio nuevo en la plataforma y cómo se le asigna, cambia o renueva su plan de suscripción.
2. [Catálogos globales y subdominios reservados](catalogos-globales-y-subdominios-reservados.md):
   cómo se administra el catálogo central de métodos de pago y cómo se protegen los nombres de
   subdominio reservados para uso interno de la plataforma.
