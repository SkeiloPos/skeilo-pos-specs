# Documentación de SkeiloPOS

SkeiloPOS es un sistema de punto de venta pensado para heladerías, granizados y negocios de
gastronomía rápida en Colombia. Esta documentación explica, función por función, cómo funciona
cada parte del sistema: para qué sirve, quién puede usarla, cómo se usa paso a paso, qué reglas y
límites tiene, y en qué se diferencia de un punto de venta tradicional.

La documentación está organizada en seis módulos. Cada módulo agrupa las funciones relacionadas y
tiene su propio índice con el orden de lectura recomendado.

1. [Acceso y Multitenancy](01-acceso-y-multitenancy/index.md): aislamiento por subdominio, inicio
   de sesión y recuperación de contraseña.
2. [Autenticación e Invitaciones de Personal](02-autenticacion-e-invitaciones-de-personal/index.md):
   cómo un administrador invita y da de alta al personal de su negocio.
3. [Pedidos y Tipos de Servicio](03-pedidos-y-tipos-de-servicio/index.md): pedidos en mesa vía QR,
   para llevar y a domicilio.
4. [Pago y Checkout](04-pago-y-checkout/index.md): métodos de pago, revisión de comprobantes y
   conciliación.
5. [Panel de Control y Operación](05-panel-de-control-y-operacion/index.md): detalle de orden e
   inicio rápido del sistema durante el turno.
6. [Administración Global](06-administracion-global/index.md): gestión de tenants, planes y
   catálogos globales (equipo interno de SkeiloPOS).
